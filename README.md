# FormaMotus

Public source repository for the FormaMotus procedural locomotion and pose-warping Skyrim plugin.

## Build

Requires Visual Studio 2022, CMake, vcpkg, and CommonLibSSE-NG. The plugin consumes the public Universal Kinematics SDK from the sibling project; set `UNIVERSAL_KINEMATICS_SDK_DIR` to that SDK directory when configuring if needed.

Build outputs, dependency installations, and source archive bundles are not included.
